## 🔥 Key Visual Metrics Dashboard
* 🌿 **Active Context Tracking:** Instantly flags your current active working Git branch.
* ⚠️ **Uncommitted Delta Warnings:** Tallies pending file modifications before you lose your progress.
* 🕒 **Commit Logs Overview:** Displays the last 3 commit authors and summaries cleanly inside your terminal frame.

## 🛠️ Build Locally (Manual Compilation)
If you prefer to compile the application logic from raw source blocks manually, clone the directory asset tree and run:
```bash
go build -o gitsummary main.go
./gitsummary
```
